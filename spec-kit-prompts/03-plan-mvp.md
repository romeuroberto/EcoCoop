/speckit.plan Planejar a implementação usando backend NestJS com TypeScript, frontend React com TypeScript e Vite, banco PostgreSQL, deploy em VM dedicada por cooperativa com Docker Compose, API REST, autenticação JWT e autorização RBAC com permissões granulares. Estruturar o projeto preferencialmente como monorepo com apps/api, apps/web e packages/shared quando fizer sentido. O backend deve ter módulos para auth, usuários/perfis/permissões, cooperativa, cooperados, compradores, materiais, unidades, rotas/mapas, coletas, estoque, triagem, vendas, financeiro, rateio, EPIs, veículos, documentos, relatórios e auditoria. O frontend deve ter layout administrativo responsivo, dashboard, telas CRUD, telas operacionais de lançamento, mapas para rotas, portal do comprador e relatórios. Priorizar integridade de estoque, rastreabilidade, auditoria, validação de permissões no backend e testes para áreas críticas. Não implementar integração com balança digital nem nota fiscal no MVP; deixar pontos de extensão documentados.
