## Fase 0 — Bootstrap

- Criar monorepo.
- Configurar backend NestJS.
- Configurar frontend React + TypeScript + Vite.
- Configurar PostgreSQL.
- Configurar Docker Compose.
- Criar autenticação base.
- Criar RBAC inicial.
- Criar layout base.

## Fase 1 — Cadastros fundamentais

- Cooperativa.
- Usuários.
- Cooperados.
- Compradores.
- Materiais.
- Categorias e subcategorias.
- Unidades de medida.
- Veículos.

- Rotas com mapa.
- Execução/registro de coleta.
- Entrada de material bruto.
- Estoque bruto.

- Venda de material.
- Baixa de estoque.
- Portal do comprador.

## Fase 5 — Financeiro completo

- Contas a receber.
